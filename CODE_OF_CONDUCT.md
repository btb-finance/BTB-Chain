# Code of Conduct

BTB Chain is built by people from every country, background and skill level, together with the AI tools they use. We want this to be a place where anyone can show up, learn and build.

## What we expect

- **Be respectful.** Disagree with ideas, never attack people.
- **Assume good intent.** Most mistakes are misunderstandings. Ask before assuming.
- **Be welcoming to newcomers.** Everyone was new once. Answer questions patiently and point people to resources.
- **Be honest.** Say when you don't know something, when you used AI help, and when you made a mistake.
- **Keep it constructive.** Criticism should help the project improve: explain what's wrong and, if you can, how to fix it.
- **Respect people's time.** Keep discussions on topic and pull requests focused.

## What's not acceptable

- Harassment, insults, threats or personal attacks
- Discrimination of any kind
- Spam, scams, unsolicited token promotion or "shilling"
- Sharing someone's private information without permission
- Deliberately misleading others or submitting code meant to cause harm

## Enforcement

If you see something that breaks these rules, report it to the maintainers through a private channel (see [SECURITY.md](SECURITY.md) for contact details) or by contacting a maintainer directly. Reports are handled confidentially.

Maintainers may remove comments, close issues or pull requests, or block contributors who break these rules, starting with a warning except in serious cases.

## Scope

This applies everywhere the project lives: GitHub issues, pull requests, discussions, and community channels representing BTB Chain.
